# SinergIA 🤖

Juego tipo buscaminas hecho con React: encuentra las 3 caras de robot escondidas en la cuadrícula de 3x3. Si seleccionas una casilla sin robot, deberás responder correctamente una pregunta de selección múltiple del **SinergIA Challenge** (Innovación, Automatización e Inteligencia Artificial) para seguir en el juego.

- Responder correctamente → ¡ganaste! 🎉
- Responder incorrectamente → pierdes 😢
- Encontrar los 3 robots → ¡ganaste! 🎉

## Requisitos

- Node.js 18+

## Desarrollo

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
```

## Stack

- React 19
- Vite
